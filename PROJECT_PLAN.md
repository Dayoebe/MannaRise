# MannaRise Development Plan

MannaRise is a pure Laravel and Livewire devotional platform. This plan keeps the dashboard custom-built without Filament.

## Phase 1

- Laravel app setup
- Livewire authentication
- Devotional categories
- Daily devotionals
- User dashboard
- Favorites
- Journal entries
- Prayer requests
- Testimonies
- Custom admin dashboard

## Phase 2

- Reading streaks
- Devotional plans
- Notifications
- Shareable devotional cards
- Audio devotionals
- PWA support

## Architecture

The application should use normal Laravel models, migrations, policies, and Livewire components. Admin screens should be built as custom Livewire pages.
