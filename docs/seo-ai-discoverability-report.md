# SEO and AI Discoverability Report

Date: 2026-05-22

## 1. Project Stack Detected

- Framework: Laravel 12 application.
- UI/runtime: Livewire 4 components rendered through Blade templates.
- Assets: Vite 7 with Tailwind CSS 4.
- Rendering model: server-rendered Laravel/Livewire HTML with JavaScript enhancements for interactive controls, PWA behavior, and canvas-based scripture cards.
- Routing: public, authenticated, and admin routes are defined in `routes/web.php`.
- Global layout/head: `resources/views/layouts/app.blade.php`.
- SEO helper: `app/Support/Seo.php`.
- SEO endpoints: `app/Http/Controllers/SeoController.php`.
- Public crawl files/endpoints: `/robots.txt`, `/sitemap.xml`, sitemap child files, `/feed.xml`, `/feed.atom`, `/llms.txt`, `/llms-full.txt`, `/ai.txt`.
- Content types found: devotionals, daily devotions, Bible reader, spiritual library books, resource hub entries, videos, audio, devotional plans, memory verses, scripture cards, prayer rooms, prayer requests, testimonies, authenticated journals/favorites/reminders/groups, and admin content operations.
- Multilingual status: app locale is English; no public multilingual routing or hreflang system was found.

## 2. SEO Issues Found

- Static `public/robots.txt` was too basic and could bypass the richer Laravel robots route.
- `/sitemap.xml` was a single URL set instead of a sitemap index with content-specific child sitemaps.
- No RSS/Atom feed discovery route was available for devotionals/resources.
- No `/llms.txt`, `/llms-full.txt`, or `/ai.txt` endpoint existed.
- About and contact pages were missing, so entity identity and public contact context were weak.
- Several public detail pages relied on generic route metadata instead of content-specific titles, descriptions, schema, and breadcrumbs.
- Search/filter query URLs could create duplicate or thin indexable variants.
- Some public media had empty alt text, and several search/filter controls lacked explicit labels.
- `APP_URL` is currently configured as `http://localhost`; production canonical/sitemap URLs require the real HTTPS domain.

## 3. AI Discoverability Issues Found

- No concise AI-readable site summary existed.
- No full Markdown digest existed for AI systems to understand core pages, topics, freshness, citation expectations, and public/private boundaries.
- Important entity facts were spread across views and config rather than summarized in an agent-readable file.
- Sitemap and feed freshness signals were incomplete.
- Citation guidance was absent.

## 7. Sitemap and Feed Status

- `/sitemap.xml` is now a sitemap index.
- `/sitemap-pages.xml` includes public static pages, devotional plans, and prayer-room pages.
- `/sitemap-devotionals.xml` includes published devotionals only.
- `/sitemap-resources.xml` includes published resource items and daily resource devotions.
- `/sitemap-library.xml` includes spiritual library books.
- `/sitemap-images.xml` includes the default site image and resource thumbnails where available.
- `/feed.xml` provides RSS discovery for latest public devotionals, daily devotions, and resource items.
- `/feed.atom` provides Atom discovery for the same public content.

Excluded from sitemaps: admin, login/register, dashboard, journal, favorites, reminders, offline library, group invite URLs, signed mail URLs, and private account surfaces.

## 8. robots.txt Policy

- Public pages, assets, icons, manifest, feeds, and AI-readable files are allowed.
- Private/admin/account routes are disallowed.
- Search/filter query variants are disallowed to reduce duplicate indexation.
- Googlebot and Bingbot are allowed.
- `OAI-SearchBot` and `ChatGPT-User` are allowed for search/discovery use.
- `PerplexityBot` is allowed for discovery.
- `GPTBot` is controlled by `SEO_ALLOW_AI_TRAINING_CRAWLERS`; default is disallowed unless the owner explicitly opts in.

## 9. llms.txt and llms-full.txt Summary

- `/llms.txt` contains a concise Markdown summary, core pages, main topics, priority content, citation guidance, sitemap, and feeds.
- `/llms-full.txt` contains a fuller entity digest, public offerings, topics, latest public content, contact status, freshness guidance, and private URL boundaries.
- `/ai.txt` provides short AI usage and citation guidance.
